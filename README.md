# Портфолио системного аналитика

Меня зовут Елизавета, я начинающий системный аналитик. До этого работала на складе (приёмка, инвентаризация, сборка, 1С) — этот опыт помогает мне проектировать процессы, где важны реальные шаги, контрольные точки и понятные роли. Сейчас прохожу обучение и формирую портфолио артефактов для стажерских позиций.

## Что здесь есть

- **BPMN-диаграммы** — моделирование процессов WMS: Обработка заказа.
- **ER-диаграммы** — модель данных для WMS и интеграции.
- **Use Case и Activity-диаграммы** — сценарии взаимодействия пользователей и системы, последовательности действий.
- **Презентации** — материалы по внедрению WMS для заказчика: проблемы, решение, архитектура, план внедрения.
- **Артефакты аналитика** — тест-кейсы.

## Где что лежит

- [BPMN](diagrams/bpmn/) — процессы WMS в нотации BPMN.
- [ER](diagrams/er/) — диаграммы модели данных.
- [Use Case](diagrams/use_case/) — диаграммы и описания сценариев использования.
- [Activity](diagrams/activity/) — диаграммы последовательностей действий.
- [Презентации](presentations/) — PDF-версии презентаций.
- [Тест-кейсы](test-case/) — тест-кейсы.
- [UI/UX](ui-ux/) - макеты пользовательских интерфейсов
